# 3DCORE

A lightweight, browser-based 3D viewer for architects, interior designers, and civil/mechanical engineers. Runs entirely in the browser — no plugins or heavy CAD install required.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — typecheck and build for production
- `npm run lint` — lint with oxlint
- `npm run preview` — preview the production build locally
